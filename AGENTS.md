# Agent instructions

- Python only. Prefer plain scripts a teammate can read and explain line by line.
- Before changing code in a folder, read that folder's `README.md` and its `AGENTS.md`.
- Do not commit virtualenvs or lockfiles. Those paths are already in [.gitignore](.gitignore).
- [requirements.txt](requirements.txt) pins Gensim and NLTK for assignment 1, and pandas, scikit-learn, and scikit-surprise for the class exercise. Library limits and task lists live in each folder's `AGENTS.md`.
